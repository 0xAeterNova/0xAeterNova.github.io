# Publish on GitHub Pages

Recommended repository name:

`0xAeterNova.github.io`

Upload the **contents of this folder** to the root of that repository, so `index.html` is directly at repository root.

In GitHub:

1. Open the repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/(root)`.
5. Save.

The expected personal Pages address is:

`https://0xaeternova.github.io/`

When updating the portfolio later, edit locally, test with `start-local.bat`, then commit/push the changed files.
