# V5 rebuild

V5 replaces the V4/V4.1 architecture instead of patching it.

## Removed
- Runtime Three.js/CDN imports.
- CDN fallback renderer.
- Flat topology circle diagram.
- Full-width search list.
- Oscillator/drone soundtrack.
- V4 Impossible Machine visual system.

## Added
- Dependency-free WebGL2 3D engine.
- Procedural cube, sphere, torus, cylinder and line geometry.
- Custom camera/matrix pipeline and object picking.
- Render-to-texture post-processing.
- Bright-pass + multi-pass blur + bloom composite.
- Chromatic transition distortion, film grain and color grading.
- Thousands of GPU particles.
- Separate visual worlds for every featured project.
- 3D Nexus topology.
- Signal Acquisition search mode.
- Rich Identity Orbit About composition.
- Original local stereo soundtrack in OGG + MP3.
- Reactive soundtrack filtering during world travel.
- Local GPU/WebGL diagnostics page.
