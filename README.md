# 0xAeterNova // Interface Zero V5

A fully custom spatial portfolio for 0xAeterNova.

## Architecture

- `index.html` — main experience.
- `css/site.css` — responsive UI/art direction.
- `js/data.js` — profile, projects, skills, links.
- `js/engine.js` — dependency-free WebGL2 engine and all 3D worlds.
- `js/app.js` — routing, UI, search, Nexus and soundtrack controller.
- `assets/profile/` — original GitHub identity assets.
- `assets/projects/` — project poster artwork.
- `assets/audio/` — original soundtrack.

## Visual modes

Origin, Project Archive, RuVigil RF Cathedral, PHANTOM Neural Mirror, Elif Kernel Forge, Breach Lab, Identity Orbit, Uplink, Nexus and Signal Acquisition all use different spatial compositions while sharing one renderer and transition system.
