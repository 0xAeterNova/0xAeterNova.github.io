# 0xAeterNova // Transmission Machine V4.2

An immersive spatial portfolio for Robotics, AI, embedded systems, reverse engineering and CTF work.

V4.2 deliberately returns to the V4 art direction while replacing the fragile CDN-dependent Three.js runtime with a fully local custom WebGL2 renderer.

Highlights:

- persistent full-screen 3D machine
- cinematic transmission/page transitions
- project-specific spatial states
- local bloom/post-processing pipeline
- audio-reactive geometry
- original looping soundtrack
- 3D signal topology map
- spatial search / signal acquisition
- responsive information lens
- original GitHub profile artwork
- project data maintained in one file
