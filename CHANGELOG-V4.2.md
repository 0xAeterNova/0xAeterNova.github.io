# V4.2 rebuild

V4.2 is based on the preferred V4/V4.1 direction, not V5.

## Fixed

- Removed all runtime CDN imports.
- Removed the "3D libraries could not load" fallback path.
- Replaced Three.js dependency with a local WebGL2 renderer.
- Entry buttons initialize independently of the 3D engine.
- About hero is contained instead of cropped/stretched.
- Information lens has bounded height and its own scrolling.
- Desktop/mobile layouts use separate safe compositions.

## Rebuilt

- System Map → live 3D Transmission Lattice with projected labels.
- Search → compact Signal Acquisition console over a 3D search field.
- About → Identity Orbit with original GitHub hero, skill spectrum and contribution field.
- Audio → original ~80-second stereo electronic soundtrack plus transition sweep effects.
- Transitions → original V4 chromatic blades plus grid flash, scan lines and 3D camera warp.
- 3D realms → richer local geometry for Origin, Archive, RuVigil, PHANTOM, Elif, Breach, Orbit and Uplink.
